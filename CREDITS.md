# Credits

## SNKRX

The game ported here is SNKRX, by a327ex
(<https://github.com/a327ex/SNKRX>, commit `6b93a64`).
Its code is under the MIT license, copyright (c) 2021 adn.
Its game design, formulas, tables, and timings are the reference of
this port.

Each asset of the original has its own license, linked from the
credits screen of the game. See `doc/assets.md`.

## The student port

A partial port of SNKRX to the reference Atmos, over `pico-sdl`, by
Kazabite Boltiz (<https://github.com/kboltiz/SNKRX>, commit `18c593b`,
folder `atmos/`). This port does not convert its code, but reuses its
task structure and its documentation: the comparison of nine behaviors
of the game in `atmos/readme.md`, which `doc/` starts from.
